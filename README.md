# Oxford
Oxford brings the atmosphere of an exclusive, slightly worn 80s reading room to your editor: a soft dark base, warm beige and ochre accents, and gently desaturated tones that stay easy on the eyes during long sessions. Strings, comments, and UI elements are subtly defined without ever feeling harsh, creating a calm, focused environment. Perfect for anyone who wants their Neovim to feel like a refined, time-polished leather chair: understated, cultured, and timeless.

# Installation Theme

To install this theme, simply use the omarchy-theme-install command:

```bash
omarchy-theme-install https://github.com/HANCORE-linux/omarchy-oxford-theme.git
```
